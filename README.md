# Chess
I made chess in python. Why, well I like to play chess and I'm decent at it.

For this project, you need to install Tkinter and the attached files and you can run it on almost anything, I think, as long as the monitor's big enough(1440x1080 or bigger).

<img width="3440" height="1440" alt="20251212_14h30m36s_grim" src="https://github.com/user-attachments/assets/96a2bd2b-5186-463f-bacf-db1644a712f0" />
The controls are simple, using a mouse, click on the piece you want to move, when it's your turn, and the board will show where you can move that piece.
<img width="3440" height="1440" alt="20251212_14h30m43s_grim" src="https://github.com/user-attachments/assets/7fd30336-83bc-4dec-bcc8-0e02d69bebbf" />
Click the highlighted square you want to move to.

After a few moves the board could look like this:
<img width="3440" height="1440" alt="20251212_14h30m56s_grim" src="https://github.com/user-attachments/assets/98de560b-6ccc-460f-8220-24d16d47d071" />
Like normal chess, you should develop your pieces and control the center. If you are able to capture a piece, it will be highlighted in all red.
<img width="3440" height="1440" alt="20251212_14h31m10s_grim" src="https://github.com/user-attachments/assets/210f0940-0003-422a-b41c-510546385d27" />
The turn counter is shown in the top right cornor along with whose turn it is

You will know if a king is in check if it have a yellow border around it.
<img width="3440" height="1440" alt="20251212_14h31m52s_grim" src="https://github.com/user-attachments/assets/6119e5a4-730c-43ed-8304-5a9e87bf9a18" />
You are unable to move into check with the king but nothing has been made to allow blocking checks and pinning pieces.
To end the game, instead of a normal checkmate, you must capture your opponent's king.
